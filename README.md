# One-Car-Garage-Simulator
A locally run, command-line Python project demonstrating object-oriented programming through inheritance and composition. Users can create and interact with petrol or electric cars. Only one car is managed at a time, and garage data is not saved after the program closes.

Features

- Create petrol and electric cars
- Turn vehicles on and off
- Display vehicle information and status
- Charge electric vehicles
- Validate user input

Concepts Demonstrated

- Classes and objects
- Inheritance and composition
- Exception handling
- Input validation

Technology: Python 3
